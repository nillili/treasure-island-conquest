# 샘플 소리 놓는 곳

여기에 파일을 넣으면 `/sfx-preview` 화면에서 **합성 소리와 나란히 비교**해 들을 수 있다.

## 이름을 이렇게 맞춰 주세요

| 파일 이름 | 언제 나는 소리 |
|---|---|
| `correct.*`  | 정답 |
| `wrong.*`    | 오답 |
| `treasure.*` | 보물 +2 |
| `storm.*`    | 폭풍 (한 판 쉼) |
| `attack.*`   | 공격권 |
| `myturn.*`   | 내 차례 |
| `claim.*`    | 땅 점령 |
| `tick.*`     | 남은 10초 |
| `gameover.*` | 게임 끝 |

확장자는 `mp3` `wav` `ogg` `m4a` `webm` 아무거나 된다. 화면이 알아서 찾는다.
전부 넣을 필요 없다. 있는 것만 비교된다.

## 크기

한 파일 **200KB 아래**를 권한다. 교실 와이파이에서 25명이 동시에 받는다.
mp3 128kbps 로 1초면 16KB 정도다 — 짧은 효과음은 넉넉하다.
